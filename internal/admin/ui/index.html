术语与权限速查

        
      


      

        
1. 核心概念与层级关系

        
    
          
  • Tenant（租户）：最高层级的隔离边界（如 default、personal、team-core）。同一 Tenant 内共享 global 记忆，不同 Tenant 之间数据完全隔离。
    • 
          
  • Principal（身份主体）：访问 MCP 服务的具体客户端、设备或成员身份（例如 MacBook 上的 Claude Code、另一台电脑上的 Codex）。
    • 
          
  • Provider / Subject（认证方式 / 唯一标识）：Provider 为认证来源（api_token / oidc / mtls）；Subject 是该来源下区分身份的唯一 ID（如 macbook-pro）。(provider, subject) 组合唯一对应一个 Principal。
    • 
          
  • Project（项目）& Marker / Remote：归属于某个 Tenant 的独立代码库或 Monorepo 子路径（workspace_path），用于存放 project 作用域记忆。可通过 Git Remote 或根目录 .engram-project UUID 文件自动匹配。
    • 
        

      


      

        
2. Tenant 角色（控制租户级与 Global 记忆权限）

        

          
            
角色Global 记忆Project 记忆典型适用场景

          
          
            

              member
              仅只读
              需在「项目与仓库识别」单独分配项目角色
              普通协作者或只读全局规范的 Agent
            

            

              global_writer
              可读写、删除及 promote 提升至全局
              需在「项目与仓库识别」单独分配项目角色
              个人主力 Agent 或需要沉淀跨项目规范的成员
            

            

              admin
              可读写、删除及 promote 提升至全局
              自动拥有该 Tenant 下所有活跃项目的 maintainer 权限
              租户管理员 / 个人全权限主账号
