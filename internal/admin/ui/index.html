术语与权限速查

        
      


      

        
1. 核心概念与层级关系

        
    
          
  • Tenant（租户）：最高层级的隔离边界（如 default、personal、team-core）。同一 Tenant 内共享 global 记忆，不同 Tenant 之间数据完全隔离。
    • 
          
  • Principal（成员 / 权限主体）：代表使用 Engram 的人或独立自动化角色（例如开发者 eagle、只读机器人 ci-bot），决定权限范围与审计归属（created_by/updated_by）。个人的多台设备、多种 Agent（MacBook 上的 Codex、Mac mini 上的 Claude 等）可共用同一个 Principal，并分别签发多张 API Token 来区分各客户端凭证。
    • 
          
  • 认证方式 / 成员标识（认证方式 / 唯一标识）：Provider 为认证来源（api_token / oidc / mtls）；Subject 是该来源下区分成员或自动化角色的唯一 ID（如 eagle）。(provider, subject) 组合唯一对应一个 Principal。
    • 
          
  • Project（项目）& Marker / Remote：归属于某个 Tenant 的独立代码库或 Monorepo 子路径（workspace_path），用于存放 project 作用域记忆。可通过 Git Remote 或根目录 .engram-project UUID 文件自动匹配。
    • 
        

      


      

        
2. 租户角色（控制租户级与 Global 记忆权限）

        

          
            
角色Global 记忆Project 记忆典型适用场景

          
          
            

              member

              需在「项目与仓库识别」单独分配项目角色
              普通协作者或只读全局规范的 Agent

              可读写、删除及 promote 提升至全局
