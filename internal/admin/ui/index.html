术语与权限速查

        
      


      

        
1. 核心概念

        
    
          
  • 租户（Tenant）：最外层的隔离边界，例如 default、personal、team-core。同一租户内共享全局记忆，不同租户之间数据完全隔离。
    • 
          
  • 成员（Principal）：使用 Engram 的人或独立的自动化角色，例如开发者 eagle、只读机器人 ci-bot。成员决定权限范围，也记录在每条知识的创建人和修改人中。同一个人的多台设备、多种 Agent 共用一个成员，再为每个客户端分别签发客户端密钥。
    • 
          
  • 认证方式与成员标识（Provider / Subject）：认证方式是身份来源，可以是客户端密钥（api_token）、单点登录（oidc）或双向 TLS 证书（mtls）；成员标识是该来源下的唯一 ID。两者组合唯一确定一个成员。
    • 
          
  • 项目（Project）：租户下的一个代码库或 Monorepo 子目录，用于存放项目记忆。客户端通过 Git 仓库地址，或仓库中 .engram-project 标记文件里的 UUID 识别所在项目。
    • 
          
  • 全局记忆与项目记忆（global / project）：全局记忆在整个租户内跨项目共享，适合通用约定；项目记忆只属于一个项目。
    •
