# Web UI 易用性与视觉修复交付

日期：2026-11-18（Asia/Singapore）。

## 背景

依据实际运行后的 12 项体验评审，修复知识浏览、成员管理和窄屏交互缺陷，并调整首页、项目和客户端页的信息层级。保留深色风格、现有技术栈和依赖。

## 已完成

1. 知识列表由固定 100 条改为分页：20/50/100 条每页、筛选总数、上一页/下一页、稳定排序；边界校验并修正过期页码。
2. 详情改为即时打开的右侧抽屉；窄屏全宽；关闭回到原列表，支持 Escape 和焦点循环。
3. 筛选和分页清空旧详情；加载期间移除旧操作；分别展示加载、空库、无结果、失败状态，提供清除筛选。
4. 成员“创建 / 绑定 / 调整租户角色”三种操作分离。重复创建返回冲突，禁止静默更名或覆盖已有角色；绑定不修改成员资料或既有角色。
5. 390px 下表单单列，账号操作收进菜单，宽表格局部滚动，页面不再横向溢出。
6. 首次使用隐藏零值统计、高级字段折叠，主操作进入首屏；完成初始化后展示少量核心统计、最近知识，快速接入默认收起。
7. 项目与客户端列表移到创建表单之前；客户端配置说明按需展开，生成密钥后打开配置；服务地址可修改，支持同源 MCP 初始化连接检查。Claude Code 接入说明补充在 `~/.claude/settings.json` 合并 `"autoMemoryEnabled": false` 的建议及复制按钮，以禁用本地自动记忆并使用 Engram 作为记忆来源。
8. Markdown 安全预览与源码切换、正文/代码复制；版本历史按时间、操作者、动作展示，并提供变更片段与原始快照。
9. 精简导航，以 URL 保存页面、知识筛选、页码、每页数量和选中项，支持刷新、后退及详情链接。凭据不会写入 URL。
10. 区分首次激活和主动改密文案，补自动填充与显示密码选项。
11. 主标签、角色和状态统一为可读中文，完善表单标签关联，统一日期格式；部分高级说明保留英文标识供技术用户定位。
12. 调整文字层级、阅读排版、留白和卡片高度；UUID 缩写并支持复制完整值；统一文件选择控件视觉。

## 文件变更

- `internal/admin/handler.go`：管理分页和成员操作语义。
- `internal/admin/ui/index.html`、`styles.css`、`app.js`：导航、布局、详情、接入及状态处理。
- `internal/admin/ui/markdown.js`：不执行原始 HTML 的 Markdown 预览及版本变更片段，无新增依赖。
- `internal/admin/handler_ui_test.go`：分页参数和数据库语义回归。
- `internal/admin/uitest/markdown.test.cjs`：渲染、安全、差异、空标题与未闭合代码块回归。

无数据库迁移、配置结构或依赖版本变更。MCP 记忆接口未修改。

## 接口契约

`GET /api/admin/memories` 保留 items，新增 total、page、page_size；page 默认 1（最大 1000000），page_size 默认 20（最大 100）。memory_id 可用于详情链接的按 ID 查询。

`POST /api/admin/principals` 新增 mode：create（缺省）、bind、update_role。已有调用方若过去依赖重复 POST 覆盖资料，现在会收到 409，需明确使用绑定或调整角色模式。mode=bind/update_role 使用 principal_id，创建使用 subject/display_name。

## 运行与交付边界

使用独立 18080/18081 测试实例和独立数据库验收，完成后清理。原有 8080 实例及数据未修改。页面资源嵌入 Go 二进制，源码变更需重新构建并启动才会生效，例如：

```bash

```
