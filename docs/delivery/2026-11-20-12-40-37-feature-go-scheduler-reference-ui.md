# 定时任务配置与界面对齐 proxystack-web

## 需求与参考

按用户确认，完整对齐 `../proxy/proxystack-web` 的任务计划配置与交互，包括预设／Cron、未来 5 次预览、配置抽屉、超时、启用开关及记录抽屉。

参考文件：

- `web/src/views/JobsView.vue`：任务列表、计划预设、配置抽屉、执行预览和历史抽屉。
- `web/src/util/cron.ts`：常见五字段 Cron 的可读说明，复杂表达式保留原文。
- `internal/app/scheduler.go`：未来执行时间预览与任务超时。

保留 Engram 现有任务参数、SafeKeep 系统设置、数据库持久化、任务审计和多实例 advisory lock，无新框架或依赖。

## 实现结果

- 列表展示任务说明、计划可读说明与原表达式、下次执行、最近一次结果、启用开关，以及立即执行／编辑／记录操作。
- 编辑改为宽度 460px 的右侧抽屉，手机上占满可用宽度，头部和底部操作保持固定。
- 预设与参考项目一致：每小时整点、每天 04:00、每周一 05:00、每月 1 日 04:00。选择“自定义”才显示 Cron 文本框；已有非预设时间按自定义回显，原固定间隔继续使用兼容模式。
- 修改计划、Cron、时区或固定间隔时，立即使旧预览失效，再防抖请求未来 5 次时间。错误时显示原因并禁用保存；迟到响应不能覆盖较新的草稿或恢复已关闭抽屉。
- 任务执行时间按选定时区显示，预览与真实执行共用 `nextScheduledRun` 计算。
- 每行“记录”打开对应任务的历史抽屉，保留分页，显示实际状态、时间、触发方式、摘要、错误及已有结构化详情；不虚构实时日志。
- 超时支持 1～86400 秒，默认 600 秒。任务收到取消后协作退出，仍在退出前持有执行锁；超时结果记录为 `timeout`，操作审计记录为失败。
- 抽屉支持 Escape、遮罩关闭、焦点约束及关闭后返回原控件；切换页面会取消抽屉待返回的请求。

## 文件与接口

- `internal/admin/ui/{index.html,app.js,styles.css,i18n.js}`：列表、抽屉、预览、超时字段、中英文及交互状态。
- `internal/scheduler/schedule.go`：无数据库副作用的 `PreviewSchedule`，返回未来 5 次执行时间。
- `internal/scheduler/{models.go,scheduler.go}`：超时配置读写、执行上下文、状态与失败审计。
- `internal/admin/{handler.go,audit_scheduler.go}`：新增受现有管理员会话和同源校验保护的 `POST /api/admin/scheduler/preview`。
- `migrations/011_scheduler_timeouts.sql`：超时列及运行状态约束。
- 对应 Go 与前端回归测试、README 和设计说明。

预览请求沿用任务配置字段，例如 `{"schedule_type":"daily","cron_expression":"0 4 * * *","timezone":"Asia/Singapore"}`；成功响应为 `{"next_runs":["...", "...", "...", "...", "..."]}`。固定间隔可发送 `{"schedule_type":"interval","interval":"30m"}`。预览不保存配置、不启停或执行任务。

`PATCH /api/admin/scheduler/tasks` 新增可选 `timeout_seconds`；未提交时保留当前值。列表响应包含该字段，历史与最近结果允许 `timeout` 状态。

## 部署与限制

- 部署前或启动时应用 `011_scheduler_timeouts.sql`；默认自动迁移会处理。关闭自动迁移时需先执行迁移，再启动新版本。
- 已有任务自动获得 600 秒超时；长任务可在编辑抽屉调整到合适值。取消依赖任务代码和底层数据库／HTTP 操作遵从 context，不强制终止 goroutine，避免锁提前释放后重复执行。
- 记录抽屉展示 Engram 已保存的结果与详情，不引入参考项目专属的统一任务中心、实时日志或其他业务任务。
- 用户明确要求完成后打标签并推送，本次版本为 `v0.0.8`。
