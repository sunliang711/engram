# 控制台账号与活跃会话

## 功能范围

系统设置中的“账号与会话”集中管理当前账号密码、活跃会话以及控制台账号。顶部账号菜单提供直接入口。界面支持中英文、深浅色主题与移动端布局。

活跃会话仅展示当前账号的设备，包含来源 IP、浏览器信息、登录时间、最近活动时间、过期时间与当前会话标记。管理员与只读账号均可刷新列表或逐个注销自己的会话。注销当前会话需要确认，完成后返回登录界面。退出登录撤销服务端凭证。

管理员可以创建管理员或只读账号、调整角色、重置密码、启用与停用账号。列表展示用户名、角色、状态及最近登录时间。用户名支持 3～64 位英文字母、数字、点、下划线与连字符；密码限制为 8～72 字节。每项账号变更均要求验证操作者的当前密码，并受操作频率限制。

## 权限与会话规则

- 管理员具有完整管理权限。只读账号可查看管理数据、修改自己的密码及注销自己的会话；账号管理、数据写入、任务执行、密钥明文、迁移与知识导出要求管理员权限。
- 账号停用与角色变更撤销该账号的全部会话。启用账号不会恢复已撤销的会话。
- 自助改密撤销该账号的全部凭证，并为当前设备签发独立的新会话。管理员重置自己的密码保留当前会话，重置其他账号的密码撤销目标账号的全部会话。
- 当前账号不能停用自己。角色与启停操作通过事务锁串行执行，确保至少保留一个启用的管理员。
- 每次登录具有独立的随机会话编号。凭证验证同时检查签名、会话记录、账号状态、密码版本及过期时间。最近活动时间最多每分钟更新一次。
- 会话记录持久化保存，应用重启后继续有效；固定签名密钥是跨重启保持登录的前提。过期记录在该账号创建会话时清理，列表不展示过期记录。
- 登录来源采用连接地址，不直接信任外部提交的转发地址。会话与账号响应不包含凭证明文、密码或密码哈希。
- 账号管理与会话注销使用统一鉴权、同源校验、禁止缓存响应及审计记录。审计信息不包含口令与登录凭证。
- 登录身份切换清理已查看的敏感信息，迟到的会话响应不能覆盖切换后的身份。

## 管理接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | /api/admin/sessions | 查询当前账号的活跃会话 |
| DELETE | /api/admin/sessions/{id} | 注销当前账号的指定会话 |
| GET | /api/admin/accounts | 查询控制台账号，仅管理员可用 |
| POST | /api/admin/accounts | 创建控制台账号 |
| POST | /api/admin/accounts/{id}/role | 调整账号角色 |
| POST | /api/admin/accounts/{id}/reset-password | 重置账号密码 |
| POST | /api/admin/accounts/{id}/enable | 启用账号 |
| POST | /api/admin/accounts/{id}/disable | 停用账号 |

账号创建请求包含 username、password、role 与 current_password；角色调整包含 role 与 current_password；密码重置包含 new_password 与 current_password；启停操作包含 current_password。role 支持 admin 与 viewer。所有接口沿用控制台 Cookie 或 Bearer 凭证及统一错误结构。

## 部署与兼容约束

数据库迁移 014 为控制台账号维护独立编号、角色、停用状态、创建及最近登录时间，并创建持久化会话表和索引。账号数据默认具有管理员角色与启用状态。自动迁移启用时随应用启动执行，否则需在应用启动前完成迁移。

缺少独立会话编号的凭证无法通过验证，需要重新登录。部署窗口应一次完成数据库迁移与全部服务实例更新。依赖和环境变量无需调整。

RESET_ADMIN 仅恢复内置 admin 账号的管理员角色与启用状态，生成临时密码并撤销该账号的会话。其他控制台账号保持各自状态。使用临时密码登录时仍须完成强制改密。

## 验证结果

- 全量 Go 竞态检测通过，管理接口回归与账号会话集成测试使用独立临时 PostgreSQL 数据库。
- 前端 99 项测试通过，覆盖只读访问边界、身份切换后的迟到响应、设备文本转义、注销确认、账号二次验证及口令清理。
- 集成测试覆盖同一秒独立登录、会话重启持久化、活动时间更新、账号唯一性、同源防护、会话归属、退出与撤销、角色调整、停用启用、密码重置、自助改密和过期验证。
- 并发降权测试确认两个管理员同时降权时仅一个操作成功，保留一个启用的管理员。
- 本地真实浏览器验证完成账号创建、当前会话注销的取消与确认、只读账号登录、中英文、深浅色及 390px 窄屏布局。
- 额外执行的记忆模块数据库验收中，项目索引条数校验预期 7 条、实际包含前置场景遗留数据共 8 条。修改前的同一版本也可复现该失败，此次功能不涉及该模块。
